# Meteorite Landings

A live demo of [csvtotable](https://github.com/vividvilla/csvtotable).

These are 1,000 records from NASA's [Meteorite Landings dataset](https://data.nasa.gov/dataset/meteorite-landings), combined from two CSV files into the single HTML file you are reading. There is no server and no network request behind any of it: the data, the stylesheet, and the scripts are all inlined into this page.
