A live demo of [csvtotable](https://github.com/vividvilla/csvtotable) - utility which converts CSV/TSV/XLSX files into interactive HTML tables.

#### Meteorite Landings

These are records from NASA's [Meteorite Landings dataset](https://data.nasa.gov/dataset/meteorite-landings) converted to a HTML file which you are reading. There is no server and no network request behind any of it: the data, the stylesheet, and the scripts are all inlined into this page.
